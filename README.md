# GLPI - Active Directory LDAP Integration

## Déploiement d’un serveur GLPI avec intégration Active Directory (LDAP)

Projet réalisé durant mon stage professionnel dans le cadre de la formation TSSR (Technicien Supérieur Systèmes et Réseaux).

---

## Description

Ce projet consiste à déployer une solution GLPI pour la gestion centralisée du parc informatique, avec intégration d’Active Directory via LDAP afin de centraliser l’authentification des utilisateurs.

---

## Objectifs

- Installer et configurer GLPI
- Mettre en place un serveur web (Apache / PHP / MariaDB)
- Intégrer Active Directory via LDAP
- Centraliser la gestion des utilisateurs
- Tester l’authentification des comptes AD
- Améliorer la gestion du support IT (tickets, inventaire)

---

## Technologies utilisées

- GLPI
- Active Directory (AD)
- LDAP
- Apache / PHP
- MariaDB / MySQL
- Windows Server
- Linux (Debian / Ubuntu)

---

## Réalisations

- Installation de GLPI sur serveur Linux
- Configuration de la base de données
- Intégration LDAP avec Active Directory
- Synchronisation des utilisateurs AD
- Test de connexion utilisateur
- Validation du système de gestion centralisée

---

## Résultat

- Plateforme GLPI fonctionnelle
- Authentification centralisée via Active Directory
- Gestion du parc informatique opérationnelle
- Accès utilisateur sécurisé et centralisé

---

## Compétences démontrées

- Administration système Linux
- Administration Windows Server / Active Directory
- LDAP configuration
- Configuration d’un serveur web Apache pour GLPI
- Support IT (gestion des tickets)
- Intégration d’infrastructures hybrides
